# Семейные расходы

Сервис учёта расходов семьи. Telegram-бот понимает текстовые сообщения и управляет тратами текущего Telegram-пользователя. Веб-панель показывает все расходы и позволяет их создавать, редактировать и удалять.

## Что реализовано

- Добавление, просмотр, изменение и удаление расходов через естественный язык в Telegram
- Автоматическое определение суммы, категории, комментария и даты через LLM
- Суммирование расходов с фильтрами по периоду и категории
- Изоляция расходов в Telegram по `from.id`; идентификатор владельца никогда не берётся из ответа LLM
- REST API для списка расходов, фильтров, получения одной записи, создания, редактирования и удаления
- Веб-панель со сводными карточками, фильтрами по члену семьи, периоду и категории
- Автоматическое создание таблиц при старте backend
- Персистентное хранилище PostgreSQL через Docker volume

1. Откройте ссылку на бота, которую выдаст BotFather, или найдите его по username.
2. Каждый член семьи должен открыть личный чат с ботом и отправить ему сообщение. Для регистрации хватит `/start`.
3. После первого сообщения Telegram ID и отображаемое имя пользователя появятся в списке членов семьи веб-панели.
4. Напишите трату обычным текстом.

Примеры:

- `кофе 350`
- `такси 1200 вчера`
- `сколько потратил на еду в этом месяце`
- `покажи траты за неделю`
- `последнее было не 350, а 450`
- `удали такси`

Категория и дата определяются моделью. Если дата не указана, предполагается сегодняшний день. При выборе цели для изменения/удаления бот ищет совпадение только среди трат автора сообщения. Формулировки на естественном языке могут интерпретироваться моделью не идеально, поэтому проверяйте результат ответа перед продолжением.

## 6. Использование веб-панели

- В верхней части показаны сумма, количество и среднее значение по текущей выборке.
- Фильтры позволяют выбрать члена семьи, начало/конец периода и категорию.
- Кнопка «Добавить трату» открывает форму создания записи.
- В каждой строке есть действия редактирования и удаления.
- Новую веб-запись можно создать для любого пользователя, который уже появился в списке после сообщения боту.
- Один запрос списка возвращает максимум 1 000 последних записей, подходящих под фильтры.

```bash
docker compose down
```

Повторный запуск:

```bash
docker compose up -d
```

Удалить контейнеры и все данные PostgreSQL:

```bash
docker compose down -v
```

Команда с `-v` необратимо удаляет сохранённую базу. Используйте её только при полном сбросе данных.

После изменения исходников пересоберите образы:

```bash
docker compose up -d --build
```
